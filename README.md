# رستوران دل بر

منوی آنلاین و سفارش از روبیکا و ایتا. سایت کاملاً استاتیک است (یک فایل `index.html`).

## انتشار روی GitHub Pages
1. این پوشه را در یک ریپوی جدید آپلود کنید.
2. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save
3. بعد از ۱ تا ۲ دقیقه آدرس سایت: `https://USERNAME.github.io/REPO/`
