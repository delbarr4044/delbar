# مزه دل بر

سایت سفارش آنلاین رستوران «مزه دل بر» (یک فایل HTML ساده).

## انتشار با GitHub Pages
1. در Settings مخزن، به بخش Pages بروید.
2. در Source گزینهٔ «Deploy from a branch» را انتخاب کنید.
3. شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و Save بزنید.
4. بعد از یکی دو دقیقه، سایت در آدرس `https://USERNAME.github.io/REPO/` بالا می‌آید.
